## 📚 핵심 개념

### 1. 변수와 자료형 (Variable, Type)

- 🧒 **비유:** 이름표 붙인 **상자**예요. `나이`라는 상자에 `10`을 넣어 둬요.
- 📖 **정확히:** 변수는 값에 붙인 이름이에요. 값에는 종류(자료형)가 있어요: 정수 `int` (10), 실수 `float` (3.14), 글자 `str` ("안녕"), 참/거짓 `bool` (True/False), 목록 `list` ([1, 2, 3]), 사전 `dict` ({"이름": "민수"}).

```python
name = "민수"
age = 10
scores = [90, 85, 100]
student = {"name": "민수", "age": 10}
print(name, age, scores[0], student["name"])
```

### 2. 조건문 (if / elif / else)

- 🧒 **비유:** **갈림길 표지판**이에요. "비가 오면 우산, 아니면 모자."
- 📖 **정확히:** 조건이 참(True)일 때만 그 아래 코드가 실행돼요. Python은 **들여쓰기(스페이스 4칸)** 로 묶음을 표시해요.

```python
temperature = 28
if temperature >= 30:
    print("너무 더워요")
elif temperature >= 20:
    print("딱 좋아요")
else:
    print("쌀쌀해요")
```

### 3. 반복문 (for / while)

- 🧒 **비유:** "운동장 **5바퀴** 돌기"(for), "종이 울릴 **때까지** 돌기"(while).
- 📖 **정확히:** `for`는 정해진 목록을 하나씩 꺼내며 반복하고, `while`은 조건이 참인 동안 반복해요. while은 조건이 영원히 참이면 **무한 반복**에 빠지니 조심해요.

```python
for i in range(1, 6):
    print(i, "바퀴")

count = 3
while count > 0:
    print(count)
    count = count - 1
print("발사!")
```

### 4. 함수 (Function)

- 🧒 **비유:** **라면 끓이기 레시피 카드**예요. 한 번 써 두면 "라면 끓여!" 한마디로 매번 같은 순서를 실행해요.
- 📖 **정확히:** 함수는 이름 붙인 코드 묶음이에요. **입력(매개변수, parameter)** 을 받아 **결과(return)** 를 돌려줘요.

```python
def add(a, b):
    return a + b

result = add(3, 4)
print(result)  # 7
```

### 5. 에러 메시지 읽기 (Traceback)

- 🧒 **비유:** 에러 메시지는 **혼내는 말이 아니라 길 안내 쪽지**예요. "몇 번째 줄에서, 무슨 문제로 넘어졌는지" 알려 줘요.
- 📖 **정확히:** Python 에러(traceback)는 **맨 아래 줄부터** 읽어요.

```text
Traceback (most recent call last):
  File "calc.py", line 3, in <module>
    print(10 / n)
ZeroDivisionError: division by zero
```

| 읽는 순서 | 무엇을 보나요? | 위 예시 |
|---|---|---|
| ① 맨 아래 줄 | 에러 **종류**와 **설명** | `ZeroDivisionError`: 0으로 나눴어요 |
| ② 그 위 `File ... line` | **어느 파일 몇 번째 줄** | `calc.py`의 3번째 줄 |
| ③ 그 줄의 코드 | 실제 문제 코드 | `print(10 / n)` → `n`이 0이었어요 |

자주 보는 에러: `SyntaxError`(문법 틀림), `NameError`(없는 이름), `TypeError`(종류가 안 맞음, 예: `"3" + 3`), `IndexError`(목록 범위 밖), `KeyError`(사전에 없는 키), `IndentationError`(들여쓰기 틀림).

### 6. AI를 "선생님"으로 쓰는 법

- 🧒 **비유:** 숙제를 **대신 해 주는 형**이 아니라, **힌트를 주는 과외 선생님**으로 써요.
- 📖 **정확히:** 연구에 따르면 AI에게 통째로 맡기면 실력이 덜 늘고, **질문하며 쓰면** 덜 손해 봐요 ([10-연구와-논문](10-연구와-논문.md)). roadmap.sh vibe-coding 로드맵의 요령도 함께 써요.
  - "**에러 메시지를 그대로** 프롬프트에 넣어라"
  - "에러가 계속되면 **가능한 원인 목록**을 만들어 달라고 해라"
  - "버그를 빨리 찾게 **로그(print)를 넣어 달라고** 해라"

문제: 1부터 30까지 출력하되, 3의 배수는 `Fizz`, 5의 배수는 `Buzz`, 둘 다면 `FizzBuzz`.

1. **먼저 15분 혼자** 풀어요.
2. 막히면 AI에게 이렇게 물어요.

```text
나는 Python 초보야. FizzBuzz를 풀고 있어.
정답 코드는 절대 주지 말고, 내 코드에서 어디가 문제인지 "질문"으로 힌트를 줘.

# 내 코드
(여기에 붙여넣기)

# 실행 결과 / 에러
(여기에 붙여넣기)
```

3. 다 풀면 이렇게 물어요.

```text
내 코드를 초보자 눈높이에서 리뷰해 줘.
1) 잘한 점 1개 2) 고치면 좋은 점 2개 3) 이 코드로 배울 수 있는 개념 1개
고친 코드를 통째로 주지 말고 설명만 해 줘.
```

✅ **Done when:** 정답 코드를 받지 않고 FizzBuzz를 완성했고, AI 리뷰에서 배운 점 1개를 log.md에 적었어요.

## 🧠 스스로 확인 문제

1. `for`와 `while`은 언제 각각 쓰나요?
2. 함수의 `return`은 무슨 일을 하나요?
3. traceback은 어디부터 읽어야 하나요?
4. `print("나이: " + 10)`을 실행하면 어떤 에러가 나고, 어떻게 고치나요?
5. 처음 배우는 내용에서 AI에게 정답 코드를 바로 받으면 안 되는 이유는?

<details><summary>정답 보기</summary>

1. `for`는 반복 횟수나 목록이 정해져 있을 때, `while`은 "조건이 참인 동안" 반복할 때 써요.
2. 함수가 계산한 결과를 함수를 부른 곳에 돌려줘요.
3. 맨 아래 줄(에러 종류와 설명)부터 읽고, 그 위의 파일 이름과 줄 번호를 봐요.
4. `TypeError`가 나요. 글자와 숫자를 바로 더할 수 없어요. `"나이: " + str(10)` 또는 `f"나이: {10}"`으로 고쳐요.
5. 연습 점수는 올라도 AI 없이 하는 실력은 떨어질 수 있어요(Bastani 2025). "할 줄 안다는 착각"도 생겨요(Prather 2024). 힌트를 받으며 스스로 풀어야 실력이 늘어요.

</details>
