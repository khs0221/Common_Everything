## ❓ 왜 배우나요?

- AI 코딩 에이전트는 **터미널에서 명령을 실행**하고 **파일을 고쳐요.** 그 명령을 읽을 줄 모르면 "허락해도 되나?"를 판단할 수 없어요. (MIT Missing Semester 2026의 첫 강의도 셸(shell)이에요.)
- AI는 **내 머릿속을 몰라요.** 설명을 잘해야 좋은 결과가 나와요.
- AI는 **그럴듯한 거짓말**도 해요. 확인하는 습관이 처음부터 필요해요.

## 📚 핵심 개념

### 1. 파일·폴더·경로 (File, Directory, Path)

- 🧒 **비유:** 컴퓨터는 커다란 **서랍장**이에요. 서랍(폴더) 안에 또 작은 서랍이 있고, 그 안에 종이(파일)가 있어요. **경로**는 "2층 → 왼쪽 서랍 → 파란 공책"처럼 찾아가는 **주소**예요.
- 📖 **정확히:**
  - **폴더(디렉터리, directory):** 파일을 담는 곳.
  - **경로(path):** 파일 위치를 적은 글. 예: `/home/minsu/projects/hello.py` (macOS/Linux), `C:\Users\minsu\projects\hello.py` (Windows).
  - **절대 경로**는 맨 꼭대기(`/`)부터, **상대 경로**는 "지금 있는 곳"부터 적어요.
  - `.` = 지금 폴더, `..` = 한 칸 위 폴더, `~` = 내 홈 폴더.

### 2. 터미널 (Terminal, Shell)

- 🧒 **비유:** 마우스로 누르는 대신 **컴퓨터에게 말(글)로 시키는 창**이에요.
- 📖 **정확히:** 터미널은 글자로 명령을 입력하는 프로그램이고, 그 명령을 해석하는 것이 **셸(shell)** 이에요. macOS·Linux는 보통 bash나 zsh, Windows는 PowerShell을 써요. Windows에서는 WSL(리눅스 환경)을 쓰면 이 교안을 따라 하기 쉬워요.

### 3. AI 챗봇 vs AI 에이전트, 그리고 컨텍스트 창

- 🧒 **비유:**
  - **챗봇**은 말로만 알려 주는 **친구**, **에이전트**는 직접 손을 움직이는 **도우미**예요.
  - **컨텍스트 창**은 AI의 **책상 크기**예요. 책상에 올려 둔 것만 보고 일해요. 책상이 너무 어지러우면 일을 못해요.
- 📖 **정확히:**
  - **LLM(대규모 언어 모델):** 글을 보고 다음 글을 만들어 내는 AI.
  - **에이전트(agent):** LLM이 도구(터미널, 파일 편집기 등)를 써서 **정보 모으기 → 행동하기 → 결과 확인하기**를 반복하는 것. (Claude Code 문서 `how-claude-code-works.md`의 "agentic loop")
  - **컨텍스트 창(context window):** AI가 한 번에 볼 수 있는 글의 양. 대화, 파일 내용, 명령 결과가 모두 여기에 쌓여요.

### 4. 좋은 프롬프트의 4요소 (Goal / Context / Constraints / Done when)

- 🧒 **비유:** 새로 온 도우미에게 주는 **심부름 쪽지**예요. "무엇을, 왜, 어떤 규칙으로, 언제 끝났다고 할지"를 적어요.
- 📖 **정확히:** OpenAI Codex best-practices [미러] 는 프롬프트에 4가지를 넣으라고 해요.

| 요소 | 뜻 | 예시 |
|---|---|---|
| **목표 (Goal)** | 무엇을 원하나요? | "할 일 목록에 마감일 기능을 추가하고 싶어" |
| **맥락 (Context)** | 관련 파일, 문서, 에러 | "코드는 todo.py 하나야. 에러 메시지는 아래에 붙였어" |
| **제약 (Constraints)** | 지켜야 할 규칙 | "새 라이브러리는 쓰지 마. 초보자가 읽을 수 있게" |
| **완료 기준 (Done when)** | 언제 끝난 건가요? | "마감일이 지난 일은 ❗로 표시되면 완료" |

ChatGPT 프롬프트 가이드(openai-cookbook)가 덧붙이는 요령이에요.
- **새 인턴에게 일 넘기듯이** 써요. 상대는 내 머릿속을 몰라요.
- **한 프롬프트에 결과물 하나.** 여러 개를 한꺼번에 시키지 않아요.
- `# Context`, `# Instructions`, `# Constraints` 같은 **제목으로 나눠** 써요.
- **메타 프롬프팅:** "이 프롬프트를 더 좋게 고쳐 줘"라고 AI에게 부탁해요.

### 5. 환각과 검증 (Hallucination & Verification)

- 🧒 **비유:** AI는 가끔 **모르는 것도 아는 척하는 친구**예요. 말투는 자신 있어도 틀릴 수 있어요.
- 📖 **정확히:** **환각(hallucination)** 은 AI가 사실이 아닌 내용(없는 함수, 없는 명령어, 가짜 링크)을 그럴듯하게 만드는 것이에요. ChatGPT 프롬프트 가이드는 **정확도 안전장치(accuracy guardrails)** 로 세 가지를 권해요.
  1. **출처를 달라고** 하기
  2. **불확실한 부분을 표시**하게 하기
  3. **스스로 점검(self-check)** 하게 하기
- ✅ 그리고 마지막 확인은 **내가** 해요. 명령어는 `--help`로, 사실은 공식 문서로 확인해요.

## 🛠️ 실습

### 실습 1. 터미널 열고 첫 인사 (20분)

1. 터미널을 열어요.
   - macOS: "터미널" 앱 / Windows: PowerShell 또는 WSL / Linux: Terminal
2. 아래 명령을 **한 줄씩** 입력하고 Enter를 눌러요. 결과를 보고 무슨 뜻인지 말해 보세요.

```bash
pwd                      # 지금 내가 있는 폴더 주소 보기 (print working directory)
ls                       # 이 폴더 안에 뭐가 있는지 보기 (list)
mkdir ai-practice        # 새 폴더 만들기 (make directory)
cd ai-practice           # 그 폴더로 들어가기 (change directory)
pwd                      # 주소가 바뀌었는지 확인
echo "안녕, 터미널!" > hello.txt   # 글을 써서 파일로 저장
cat hello.txt            # 파일 내용 보기
cp hello.txt copy.txt    # 복사하기
mv copy.txt hi.txt       # 이름 바꾸기 (move)
ls                       # hello.txt와 hi.txt가 보이나요?
cd ..                    # 한 칸 위로 나가기
```

> ⚠️ `rm`(지우기)은 **휴지통 없이 바로 지워요.** 연습 폴더 안에서만, 파일 이름을 두 번 확인하고 쓰세요. `rm -rf`는 지금은 쓰지 마세요.

✅ **Done when:** `ai-practice` 폴더 안에 `hello.txt`와 `hi.txt`가 있고, `pwd`의 결과가 무슨 뜻인지 설명할 수 있어요.

### 실습 2. 경로 보물찾기 (20분)

1. `~/ai-practice` 안에 `a/b/c` 폴더를 만들어요: `mkdir -p a/b/c`
2. `cd a/b/c`로 들어간 뒤, **상대 경로만으로** `hello.txt`를 열어요: `cat ../../../hello.txt`
3. 이번엔 **절대 경로**로 열어요. (`pwd`로 주소를 확인하고 써 보세요.)
4. `cd ~`로 홈에 갔다가, `cd -`로 직전 폴더로 돌아와요.

✅ **Done when:** 같은 파일을 상대 경로와 절대 경로 두 가지로 열 수 있어요.

### 실습 3. 명령어 설명서 읽기 (10분)

```bash
ls --help        # Linux/WSL
man ls           # macOS/Linux (q를 누르면 나가요)
```

✅ **Done when:** `ls`에 숨김 파일까지 보여 주는 옵션이 무엇인지 설명서에서 직접 찾았어요. (AI에게 묻지 말고!)

### 실습 4. 프롬프트 고쳐 쓰기: 보통 → 좋음 → 최고 (30분)

ChatGPT(또는 다른 AI 챗봇)를 열고, 같은 부탁을 세 번 다르게 해 보세요.

**① 보통 (Okay)**
```text
로그인 기능 만들어줘
```

**② 좋음 (Good)**
```text
Python으로 간단한 로그인 기능을 만들고 싶어.
아이디와 비밀번호를 입력받아서 맞으면 "환영해요"를 출력해 줘.
```

**③ 최고 (Excellent)**: 4요소를 모두 넣어요.
```text
# 목표
Python 연습용으로 터미널에서 동작하는 아주 간단한 로그인 프로그램을 만들고 싶어.

# 맥락
- 나는 Python을 2주째 배우는 초보야.
- 진짜 서비스가 아니라 연습용이야.

# 제약
- 외부 라이브러리 없이 기본 Python만 써 줘.
- 비밀번호를 코드에 그대로 적는 게 왜 위험한지도 한 줄로 알려 줘.
- 코드 한 줄마다 짧은 한국어 주석을 달아 줘.

# 완료 기준
- 맞는 비밀번호면 "환영해요", 3번 틀리면 "잠겼어요"가 출력되면 완료.
- 내가 직접 테스트할 수 있는 입력 예시 3개도 같이 줘.
```

**④ 메타 프롬프팅:** 마지막으로 이렇게 물어보세요.
```text
위 ③ 프롬프트를 더 좋게 고쳐 줘. 무엇이 빠졌는지도 알려 줘.
```

✅ **Done when:** ①②③의 답을 비교해서 "무엇이 달라졌는지" 3줄로 log.md에 적었어요.

### 실습 5. 환각 잡기 놀이 (20분)

```text
터미널에서 쓰는 ls 명령의 옵션 5개를 알려 줘.
각 옵션마다 확신 정도(높음/중간/낮음)를 표시하고,
확인할 수 있는 방법도 알려 줘.
```

1. AI가 알려 준 옵션을 **`ls --help` 또는 `man ls`로 직접 확인**해요.
2. 틀린 것이 있으면 표시해요. 없으면 "모두 맞음"이라고 적어요.

✅ **Done when:** AI 답을 공식 설명서와 하나하나 비교한 표를 만들었어요.

## 🧠 스스로 확인 문제

1. 지금 `/home/minsu/projects`에 있어요. `cd ..`를 하면 어디로 가나요?
2. 챗봇과 에이전트의 차이를 "친구"와 "도우미"로 설명해 보세요.
3. 좋은 프롬프트의 4요소는 무엇인가요?
4. AI가 알려 준 명령어를 그대로 믿으면 안 되는 이유는? 어떻게 확인하나요?
5. 컨텍스트 창을 "책상"에 비유하면, 책상이 너무 어지러우면 어떤 일이 생기나요?

<details><summary>정답 보기</summary>

1. `/home/minsu`로 가요. `..`는 한 칸 위 폴더예요.
2. 챗봇은 말로만 알려 주는 친구예요. 에이전트는 도구(터미널, 파일 편집)를 써서 직접 일하고, 결과를 확인하며 반복하는 도우미예요.
3. 목표(Goal), 맥락(Context), 제약(Constraints), 완료 기준(Done when).
4. AI는 없는 옵션이나 명령을 그럴듯하게 만들어 낼 수 있어요(환각). `--help`, `man`, 공식 문서로 확인해요.
5. 필요한 것을 찾기 어려워지고 일을 잘 못해요. Claude Code 문서도 "컨텍스트 창이 차면 성능이 떨어진다"고 설명했어요. 그래서 관련 있는 것만 올려 두는 게 좋아요.

</details>

## ⚠️ 흔한 실수

| 실수 | 왜 문제인가요? | 이렇게 해요 |
|---|---|---|
| 지금 어느 폴더인지 모르고 명령 실행 | 엉뚱한 곳에 파일이 생기거나 지워져요 | 명령 전에 `pwd` |
| 파일 이름에 띄어쓰기 사용 | 터미널이 두 개의 이름으로 알아들어요 | `my-file.txt`처럼 `-`나 `_` 사용 |
| `rm`을 가볍게 사용 | 휴지통 없이 바로 사라져요 | 연습 폴더에서만, 두 번 확인 |
| "~해줘" 한 줄로 끝내기 | AI가 내 사정을 몰라서 엉뚱한 답을 줘요 | 4요소를 채워요 |
| 한 번에 여러 개를 부탁 | 결과물이 섞이고 품질이 떨어져요 | 한 프롬프트에 결과물 하나 |
| AI 답을 확인 없이 복사 | 환각일 수 있어요 | 출처 요구 + 직접 확인 |
