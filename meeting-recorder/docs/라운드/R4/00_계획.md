# R4 계획서 — medium 모델, 분야 용어 반영

작성: 총괄, 2026-11-24

## 1. 사용자 요청
- 음성 인식 모델을 medium 으로 올린다.
- 전기차용 배터리 모듈의 설계·성능, 공정능력, 품질관리, 공정 분야의 영어 용어를 웹에서 모아 프로그램에 넣어 둔다(사용자가 목록을 직접 만들기에는 범위가 넓음).
- 회의는 주로 영어, 가끔 한국어. 용도는 녹음과 대화록, 요약은 Copilot.

## 2. 할 일
### 2-1. 모델 선택(기본 medium)
- 화면에 처리 품질 선택을 둔다: **정확(medium, 기본)** / **빠름(small)**. 설정은 저장한다. 기존 녹음 다시 처리에도 적용된다.
- 두 모델을 모두 exe 묶음에 넣는다(실행 중 내려받기 없음). 사용자 PC(메모리 7.7GB, 내장 그래픽)에서 medium 이 너무 느리면 사용자가 '빠름'으로 바꿀 수 있어야 한다.
- 발언 단위 언어 판별(R3)은 가벼운 쪽으로 유지할 수 있으면 유지한다(판별은 small, 옮기기는 medium 같은 조합이 정확도·시간에 유리한지 측정해 결정). 두 모델을 동시에 메모리에 올리지 않도록 한다.
- 측정: medium(int8, CPU) 의 처리 시간과 메모리 최고치를 small 과 같은 표본(영어 10분, 혼합 표본)으로 비교한다. 메모리 최고치가 4GB 를 넘으면 낮출 방법을 찾고, 못 낮추면 보고한다. 화면에 예상 처리 시간 안내(예: 녹음 길이의 약 N배)를 측정값에 근거해 표시한다.
- 묶음 크기 증가(약 0.5GB → 약 2GB 추정)에 따른 CI 시간·캐시·업로드 한도를 확인한다.

### 2-2. 분야 용어 반영
용어 파일은 조사 담당이 만든다(구현자는 이 두 파일의 내용을 만들지 않고 읽어 쓴다).
- `meeting-recorder/glossary/hint_terms.txt`: 인식 힌트용. 회의에서 자주 말하고 잘못 들리기 쉬운 약어·전문어 80개 이내.
- `meeting-recorder/glossary/glossary_full.txt`: Copilot 교정용 전체 목록(300개 이내).
- 형식: UTF-8, 한 줄에 용어 하나, `#` 으로 시작하는 줄은 주석, 빈 줄 허용.

구현
- (a) **인식 힌트**: `hint_terms.txt` 를 whisper 에 힌트로 준다(faster-whisper 의 initial_prompt 또는 hotwords. 설치된 버전 소스로 동작·길이 한도를 확인해 선택). 영어 묶음에 적용하고, 한국어 묶음에도 적용할지는 측정해 정한다(한국어 문장 안의 영어 용어). 길이 한도를 넘는 용어는 앞에서부터만 쓰고 화면·로그에 알린다.
- (b) **Copilot 교정**: `Copilot용.txt` 의 지시문에 "아래 용어 목록의 표기를 기준으로, 기록에서 잘못 들린 것으로 보이는 단어를 문맥에 맞게 바로잡아 요약하라"는 취지와 `glossary_full.txt` 목록을 넣는다. 기록 전문은 그대로 둔다.
- 두 파일은 exe 묶음의 프로그램 폴더에 그대로 두어 사용자가 메모장으로 고칠 수 있게 한다. 사용자가 고친 파일을 다음 판으로 옮기는 방법을 README 에 적는다.
- 측정(필수): 용어가 들어간 영어 문장 표본(합성음 가능, 출처 기록)으로 힌트 없음/있음의 용어 적중률을 small·medium 각각 비교한다. 부작용도 잰다: 용어가 없는 일반 음성에서 말하지 않은 용어가 끼어드는 건수, 무음·잡음 구간에서의 끼어듦. 부작용이 확인되면 힌트 개수를 줄이거나 방식을 바꾼다. 효과가 없으면 없다고 보고한다.

### 2-3. 감사 이월
- R3 N1(확실하지 않은 짧은 발언의 언어 보정): medium 으로 바뀌며 달라지는지 확인하고, 간단히 줄일 수 있으면 반영.
- 작은 마이크 입력에서 발언이 빠지는 문제(R3 구현자 발견): 말소리 찾기 앞의 음량 맞추기를 검토해, 부작용 없이 넣을 수 있으면 넣는다.

## 3. 하지 않는 것
교정 사전(틀린 표기 → 맞는 표기 자동 치환), 프로그램 안 요약, 회사·고객·제품 고유 이름 수록(사용자가 파일에 직접 추가).

## 4. 제약
R1 계획서 5절과 같다. 저장소가 공개 상태이므로 문서·주석·용어 파일에 사용자의 회사·고객·업무를 추정할 수 있는 서술을 넣지 않는다(일반적인 분야 용어집으로만 서술). 용어 목록은 공개 자료의 일반 용어만, 출처를 기록한다. 실행 중 외부 접속 없음.

## 5. 완료 기준
- pytest 통과, 윈도우 빌드와 `--selftest` 성공(두 모델 모두 불러오기 확인).
- medium/small 시간·메모리 측정표, 용어 힌트 효과·부작용 측정표.
- 메모리 최고치 4GB 이하(또는 초과 사유와 대안 보고).
