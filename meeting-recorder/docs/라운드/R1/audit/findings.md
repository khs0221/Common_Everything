## pytest (감사자 실행)
새 가상환경에서 48 통과, 1 실패(tkinter 없음으로 selftest 항목 실패, F10), 1 실행 안 함. selftest 표본 42.5초 처리 11.3초, 메모리 최고치 1,128MB.

## changes.md 와 어긋난 점
1. "두 트랙 0.15초 안"은 장치 열기 시간이 0 인 가짜 장치에서만 성립(F3).
2. "화면 없이 49 passed"는 tkinter 설치 환경에서만 성립(F10).
3. CI 가 계정 문제로 시작도 못 한 사실이 없음(F4).
4. COM 스레드·재연결 문제(F1·F2)가 미검증 목록에 없음.
5. 2시간 전체 메모리는 측정이 아니라 합산 추정.

## 확인하지 못한 것
윈도우 실기기와 exe 실행 전부, 화면 시험, 2시간 전체 파이프라인, 실제 회의 음성 정확도, 바이너리 내부 접속 여부, 모델 학습 데이터·DLL 재배포의 법적 조건.
