## 만든 것
- 녹음: 마이크(나)와 스피커 출력(상대방)을 별도 트랙으로 저장. 두 트랙 시간축 보정, 장치 끊김 시 재연결과 화면 경고.
- 글로 옮기기: faster-whisper small(int8, CPU). 발언자 구분: sherpa-onnx(pyannote segmentation 3.0 + CAM++).
- 결과물: 회의 폴더에 녹음 2개, `기록.md`, `Copilot용.txt`. 참석자 이름 지정 뒤 다시 쓰기.
- 화면: tkinter 한 창. 배포: PyInstaller + 모델 동봉 zip(약 600MB), GitHub Actions 윈도우 빌드와 `--selftest`.
- 실행 중 외부 접속 없음(파이썬 소켓 단계 차단, 모델 동봉). 차단 범위의 한계는 README 에 적음.
