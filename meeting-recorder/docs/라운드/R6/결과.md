# R6 결과 — 묶음 크기 줄이기, 덧붙는 글 방지, 짧은 한국어 발언 보완

작성: 총괄, 2026-11-26

## 결론
묶음을 약 2.1GB 에서 약 1.3GB 로 줄였습니다. 감사 1차 치명 1·중요 2 → 수정 1회 → 재감사 중요 1 → 수정 2회 → 재감사 치명 0·중요 0·보통 1·경미 1. 윈도우 빌드와 자체 시험 통과.

## 바꾼 것
- turbo 모델을 8비트로 저장한 변환본으로 교체(빌드 때 직접 변환, 해시 검사). 모델 파일 1.6GB → 0.81GB, 불러오기 3~8초 → 1초 미만.
- '빠름' 선택 제거. 언어 판별 모델은 small 유지(base 는 짧은 발언에서 나빠 되돌림).
- 묶음 끝의 무음에서 말하지 않은 글이 덧붙는 것을 막는 좁은 규칙. 실제 발언을 버리던 넓은 규칙은 제거.
- 영어 발언 사이에 낀 짧은 한국어 발언이 빠지던 문제 보완: 1.5초 조각 4/6 → 6/6. 1초 이하는 한계로 남음.
- CI: 모델 받기 시간 제한·재시도, 리눅스 변환 작업과 윈도우 빌드의 캐시 이름 통일.
- 장치: 실패한 열기 정리, 재연결 때 마지막 성공 방법 우선, 기존 조합 먼저 시도. 용어 끼어듦 검사 보강.
- README '알려진 한계' 절, 인계 문서 `docs/HANDOFF.md`.

## 검토만 한 것
영어 전용 모델(parakeet-tdt-0.6b-v2) 혼합 구성: 측정에서 영어 처리 0.4~0.56배, 잡음 구간 지어낸 글 0, 영어 오류율 0.037(turbo 0.040), 용어 적중 36/47(turbo 38). 사용자 결정으로 넣지 않음.

## 측정(4코어 컨테이너)
- 영어 단어 오류율 0.040, 한국어 글자 오류율 0.065(8비트 저장 전 0.058), 용어 적중 38/47, 혼합 64발언 64/64.
- 짧은 한국어 다시 보기는 조각 하나에 약 10초가 더 든다(상한 없음, 감사 H1).
