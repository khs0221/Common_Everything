## 수집 방법과 선정 기준
- 웹 검색 8회와 페이지 열람 5회로 분류별 자료를 찾았습니다. 열람이 막힌 곳(MDPI, TÜV SÜD는 403)은 검색 결과 요약에 나온 용어만 썼습니다.
- 정의 문장은 가져오지 않고 용어 표기만 모았습니다. 회사·제품·고객 고유 이름은 넣지 않았고 표준 번호만 넣었습니다.

## 확인하지 못했거나 표기가 갈리는 용어
검색 결과에서 직접 확인하지 못했고 분야의 일반 지식으로 넣은 용어입니다. 필요 없으면 지우십시오.
- 구조: CTC, CSC, cell supervision circuit, HV connector, tie rod 외 일부 부품 이름
- 시험: SOHp 외 SOP, DoD, CC-CV, lithium plating, preload, peel strength, pull test, shear test, HiPot의 dielectric withstand·insulation resistance(검색에서 찾지 못함)
- 공정: formation, aging, degassing, helium leak test, OCT, thermography, plasma cleaning, cell sorting·grading·matching, tact time, FPY, OEE
- SPC: Anderson-Darling, rational subgroup, Western Electric rules, X-bar S chart, I-MR chart, ndc, attribute agreement analysis, OOC, OOS
- 품질: 8D, FMEA-MSR, action priority, RPN, DVP&R, KPC, KCC, CTQ, 4M change, run at rate, golden sample, NCR, SCAR, CAPA, ECN, FAI(검색에서 세부 확인 못함. RPN·Action Priority·8D·poka-yoke는 검색이 다루지 못했다고 명시됨)
- 표준: GB/T 31485, GB/T 31486, ISO 26262, IEC 62133·IEC 62619·UL 1642·UL 9540A·SAE J2464는 검색 결과에 이름만 나옴. ISO 12405-1·-3·-4와 IEC 62660-1·-2·-3 같은 부 번호 일부도 같습니다.
- 소재: LTO·CEI·SEI는 확인. NMC811 같은 숫자 조합, LiPF6, PVDF, high-nickel, cobalt-free, ceramic coating, sodium-ion은 일반 지식입니다.

표기가 여러 가지인 용어
- Gage R&R / Gauge R&R (미국식과 영국식. 목록은 Gage R&R로 통일)
- X-bar R chart / Xbar-R chart, I-MR chart / IMR chart
- poka-yoke / poka yoke / mistake proofing
- HiPot / hi-pot / high potential test
- cell-to-pack / cell to pack, 약어 CTP
- ECE R100 / UNECE R100 / UN R100 (둘 다 넣음)
- 5 Why / 5 Whys, Ishikawa / fishbone
- first article inspection / FAI와 first pass yield / FPY는 약어가 달라 별도 줄
- SOP는 state of power와 start of production으로 겹칠 수 있어 힌트 목록에서는 뺐습니다.
- CEI는 일반 사이클링에서 생기는지 자료마다 설명이 다릅니다(용어 자체는 유효).

## 조사에서 막힌 점
- 검색 도구가 요약만 주어 원문 대조를 못 했습니다. MDPI, TÜV SÜD 페이지는 403으로 열람하지 못했습니다. batterydesign.net 용어집 페이지는 본문이 비어 돌아왔습니다.
- AIAG 매뉴얼과 IATF 16949, 표준 문서 자체는 유료라 열람하지 못했습니다.
