# 쓰는 라이브러리·모델의 라이선스

작성: 2026-11-23 (R1), 보완: 2026-11-24 (R1 수정 1회차, 감사 F7). 버전은 `requirements.txt`, 모델 해시는 `mrec/models.py` 기준입니다.
'미확인' 은 이번에 원문을 확인하지 못한 조건입니다.
"상업적 사용" 은 회사 PC 에서 업무용으로 쓰는 것을 말합니다. 법률 검토를 대신하지 않습니다.

## 분야 용어 파일(`glossary/`, R4)

`hint_terms.txt`·`glossary_full.txt` 는 공개 자료의 일반 분야 용어를 모은 목록이며, 출처는 `docs/용어/출처.md` 에 있습니다(조사 담당 작성). 프로그램은 이 파일을 읽기만 합니다.

## 확인이 더 필요한 것(미확인)
- libiomp5md.dll 의 재배포 조건 원문(인텔).
- Microsoft Visual C++ 런타임 재배포 조건 원문.
- 모델 학습 데이터의 이용 조건이 모델 사용에 미치는 영향(법률 판단 필요): Whisper(학습 데이터 비공개), CAM++(VoxCeleb, CC BY 4.0), pyannote(공개 데이터셋 여러 개).
- 표본 음성의 piper 모델이 이어 학습한 원 음성(lessac)의 조건.
- cudnn 을 뺀 묶음이 윈도우에서 실제로 동작하는지(리눅스 묶음에는 원래 없음) — CI selftest 로 확인 필요.
