# 쓰는 라이브러리·모델의 라이선스

작성: 2026-11-23 (R1). 버전은 `requirements.txt`, 모델 해시는 `mrec/models.py` 기준입니다.
"상업적 사용" 은 회사 PC 에서 업무용으로 쓰는 것을 말합니다. 법률 검토를 대신하지 않습니다.

- libiomp5md.dll 의 정확한 라이선스 문서(인텔 재배포 조건) — R2 에서 확인.
